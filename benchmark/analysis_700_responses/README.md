# E2seq 700-Response Analysis Archive

This directory contains the complete locked benchmark response archive used for the comparative analysis.

## Contents

- `E2seq/`: 350 independently generated E2seq responses.
- `raw/`: 350 independently generated direct-model responses.
- Total: 700 Markdown responses.
- Each system contains 7 model families, 10 diseases and 5 repeated answers per model–disease condition.

The files are preserved as generated. No answer was re-selected, truncated or rewritten during packaging. API keys and machine-specific configuration are not included.

This archive is published on the dedicated branch `analysis/benchmark-700-answers`; `main` is unchanged.
